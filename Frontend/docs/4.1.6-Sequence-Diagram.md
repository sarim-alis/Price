## Sequence Diagram Notation

### **Symbols Used**

- **Actor**: External user (Customer, Seller, Admin)
- **Object/Component**: System components (App, Service, Database)
- **Lifeline**: Vertical dashed line showing object's lifetime
- **Activation**: Vertical rectangle showing when object is active
- **Message Arrow**: 
  - `─────>` Synchronous call
  - `<─────` Return
  - `──────┐` Self-call (internal method)
  - `      │`
  - `<─────┘`

### **Message Types**

1. **Synchronous Message**: Caller waits for response
2. **Return Message**: Response back to caller
3. **Self Message**: Object calling its own method
4. **Create Message**: Object creation
5. **Destroy Message**: Object destruction (not shown in examples)

## Key Interaction Patterns

### **1. Validation Pattern**
- Input → Validate → Process → Save
- Seen in: Registration, Login, Product Addition

### **2. AI Integration Pattern**
- Request → Fetch Data → AI Processing → Save Result
- Seen in: Price Prediction, Reviews, Recommendations, Fraud Detection

### **3. Transaction Pattern**
- Initiate → Validate → Process Payment → Update State → Confirm
- Seen in: Order Processing

### **4. Service Layer Pattern**
- UI → Service → Database
- Service encapsulates business logic
- Seen in: All diagrams
