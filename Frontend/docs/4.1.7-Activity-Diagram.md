## Business Rules Implemented

### **Registration Flow**
1. Email must be unique
2. Password must meet complexity requirements
3. Verification email sent automatically
4. JWT token generated upon successful registration

### **Login Flow**
1. Maximum 5 login attempts before lockout
2. Last login time updated
3. Session expires after 24 hours
4. Invalid credentials do not reveal which field is wrong (security)

### **Product Purchase Flow**
1. User must be logged in to purchase
2. Stock validation before payment
3. Payment processed before order confirmation
4. Stock decremented only after successful payment
5. Order confirmation sent via email

### **Price Prediction Flow**
1. All specification fields are mandatory
2. Anonymous users can use prediction
3. Logged-in users have prediction history
4. Similar products shown based on specs

### **Review Submission Flow**
1. User must be logged in
2. User must have purchased product to review
3. One review per product per user
4. AI sentiment analysis on all reviews
5. Summary generated when ≥5 reviews exist

### **Seller Listing Flow**
1. Seller must be verified
2. Mandatory fields validation
3. Images required (min 1, max 5)
4. AI score calculated automatically
5. External data fetched if available

### **Order Processing Flow**
1. Stock checked at order creation and payment
2. Payment gateway timeout: 10 minutes
3. Failed payments release reserved stock
4. Status updates trigger notifications
5. Tracking number generated on shipment

## Exception Handling

### **Common Exception Paths**

1. **Validation Errors** → Show Error → Return to Input
2. **Database Errors** → Log Error → Show Generic Error → Retry Option
3. **Payment Failures** → Rollback Transaction → Notify User → Offer Retry
4. **External Service Timeout** → Use Cached Data → Continue with Degraded Service
5. **Stock Unavailable** → Cancel Order → Refund → Notify User
