## Component Details by Layer

### **PRESENTATION LAYER (Client Tier)**

**Purpose**: User interface and user experience components that interact with end users.

**Components**:

1. **Web Application (React/Next.js)**
   - Customer browsing and shopping interface
   - Product search, filtering, and comparison
   - Price prediction tool interface
   - User authentication and profile management
   - Order tracking and history
   
2. **Mobile Application (iOS/Android)**
   - Native mobile experience for customers
   - On-the-go shopping and price checks
   - Push notifications for orders and recommendations
   
3. **Admin Panel (React)**
   - Seller product management dashboard
   - Analytics and reporting
   - User management
   - Fraud detection monitoring

**Communication**: HTTPS/REST API calls to Business Logic Layer

---

### **BUSINESS LOGIC LAYER (Server Tier)**

**Purpose**: Core application logic, business rules, and orchestration of system operations.

**Components**:

#### **API Gateway / Load Balancer**
- Entry point for all client requests
- Request routing and load distribution
- Rate limiting and throttling
- API versioning management

#### **Authentication & Authorization Module**
- JWT token generation and validation
- Session management
- Role-based access control (Customer/Seller/Admin)
- OAuth integration

#### **Core Business Modules**:

**1.0 User Management**
- **Functions**: User registration, login, profile management
- **Communication**: Database queries to D2 (User DB)
- **Protocol**: Internal function calls, SQL via Prisma ORM

**3.0 AI Comparison and Recommendation**
- **Functions**: Product comparison, personalized recommendations
- **Communication**: 
  - Database queries to D1 (Product DB)
  - API calls to AI Services (HTTPS)
- **Protocol**: REST API, SQL queries

**4.0 Review Summarization**
- **Functions**: AI-powered review sentiment analysis and summarization
- **Communication**: 
  - Database queries to D1 (Product DB - Reviews)
  - API calls to AI Services (HTTPS)
- **Protocol**: REST API, SQL queries

**5.0 Seller Management**
- **Functions**: Product listing, inventory management, seller verification
- **Communication**: Database queries to D1, D2
- **Protocol**: SQL queries via Prisma ORM

**6.0 Fraud Detection**
- **Functions**: Seller verification, fraud scoring, suspicious activity detection
- **Communication**: 
  - Database queries to D3 (Transaction Logs)
  - API calls to AI Services (HTTPS)
- **Protocol**: REST API, SQL queries

**7.0 Transaction Management**
- **Functions**: Order processing, payment handling, transaction logging
- **Communication**: 
  - Database queries to D3 (Transaction Logs)
  - API calls to Payment Gateway (HTTPS)
- **Protocol**: REST API, SQL queries

**8.0 NLP Chatbot**
- **Functions**: Customer query handling, AI-powered responses
- **Communication**: 
  - Database queries to D2 (Chatbot logs)
  - API calls to AI Services (HTTPS)
- **Protocol**: REST API, SQL queries

#### **2.0 Data Integration Layer**
- **Functions**: External API integration, data validation, data enrichment
- **Communication**: 
  - API calls to External Data APIs (HTTPS)
  - Database queries to D1 (External Data table)
- **Protocol**: REST API, SQL queries

**Communication**: 
- Upward: HTTPS/REST responses to Presentation Layer
- Downward: Database queries (SQL via Prisma ORM) to Data Storage Layer
- External: HTTPS/REST API calls to External Services Layer

---

### **DATA STORAGE LAYER (Database Tier)**

**Purpose**: Persistent data storage, data integrity, and data retrieval.

**Components**:

#### **D1: Product Database (PostgreSQL)**
- **Tables**: 
  - Mobile (product catalog with specifications)
  - Prediction (price prediction history)
  - Product (marketplace listings)
  - Review (customer reviews)
  - Review_Summary (AI-generated summaries)
  - External_Data (third-party product information)
  
- **Indexes**: brand, price, createdAt
- **Relationships**: Product → Review (1:*), Product → External_Data (1:*)

#### **D2: User Database (PostgreSQL)**
- **Tables**: 
  - User (base user entity)
  - Customer (buyer profiles)
  - Seller (vendor profiles)
  - Admin (system administrators)
  - Chatbot_Log (NLP interaction history)
  - AI_Recommendation (personalized recommendations)
  
- **Relationships**: User → Customer (1:1), User → Seller (1:1)

#### **D3: Transaction Logs (PostgreSQL)**
- **Tables**: 
  - Order (purchase transactions)
  - Order_Item (order details)
  - Payment (payment information)
  - Transaction_Log (audit trail)
  - Fraud_Detection (fraud checks)
  
- **Relationships**: Order → Payment (1:1), Order → Order_Item (1:*)

**Communication**: SQL queries via Prisma ORM from Business Logic Layer

---

### **EXTERNAL SERVICES LAYER**

**Purpose**: Third-party services and AI capabilities that extend system functionality.

**Components**:

#### **AI Services**
- **Price Prediction Model**: ML model for mobile price estimation
- **Recommendation Engine**: Collaborative filtering and content-based recommendations
- **NLP Chatbot Service**: Natural language processing and response generation
- **Sentiment Analysis**: Review sentiment scoring
- **Fraud Detection AI**: Anomaly detection and fraud scoring

**Communication**: REST API / gRPC (HTTPS)

#### **Payment Gateway**
- **Services**: Stripe, PayPal, or similar payment processors
- **Functions**: Transaction processing, payment confirmation, refunds
- **Communication**: REST API (HTTPS), Webhooks for callbacks

#### **External Data APIs**
- **Mobile Specifications Database**: Third-party mobile specs APIs
- **Market Pricing APIs**: Real-time market price data
- **Product Information Services**: Brand and product data enrichment
- **Communication**: REST API (HTTPS)

## Communication Protocols Summary

| Layer | Communication Type | Protocol |
|-------|-------------------|----------|
| Presentation → Business Logic | HTTP/HTTPS REST API | JSON over HTTPS |
| Business Logic → Data Storage | Database Queries | SQL via Prisma ORM (PostgreSQL) |
| Business Logic → External Services | HTTP/HTTPS REST API | JSON over HTTPS, Webhooks |
| Business Logic (Internal) | Function Calls | Node.js internal function calls |

## Architecture Principles

1. **Separation of Concerns**: Clear separation between presentation, business logic, and data layers
2. **Scalability**: Stateless business logic layer allows horizontal scaling
3. **Security**: JWT-based authentication, HTTPS encryption, SQL injection prevention via ORM
4. **Modularity**: Each business module (1.0-8.0) can be independently developed and deployed
5. **API-First Design**: RESTful APIs enable multiple client applications (web, mobile, admin)
6. **Data Integrity**: PostgreSQL ensures ACID compliance for critical transactions
7. **External Integration**: Data Integration Layer (2.0) abstracts external API complexity
8. **AI-Powered**: Multiple AI touchpoints enhance user experience and business intelligence
